# Formattage binaire de notre classe

target = "post_index_exacerbations365"

df_bin = df.with_columns(
    pl.when(pl.col(target).cast(pl.Int64, strict=False) > 0)
      .then(1)
      .otherwise(0)
      .alias("target_bin")
)

# Calcul des % de manquants par classe

vars_to_test = [
    col for col in df.columns
    if col not in [target, "patid"]
]

df_missing = (
    df_bin
    .select(
        ["target_bin"] +
        [
            pl.col(v).is_null().cast(pl.Int8).alias(v)
            for v in vars_to_test
        ]
    )
)

# Agrégation par classe
df_missing_pct = (
    df_missing
    .group_by("target_bin")
    .agg([
        (pl.col(v).mean() * 100).alias(v)
        for v in vars_to_test
    ])
)

# Mise en forme final 

df_missing_pct = (
    df_missing_pct
    .transpose(
        include_header=True,
        header_name="variable",
        column_names=["classe_0", "classe_1"]
    )
)

df_missing_pct

results = []

for var in vars_to_test:
    tab = (
        df_bin
        .select([
            pl.col(var).is_null().cast(pl.Int8).alias("missing"),
            pl.col("target_bin")
        ])
        .to_pandas()
    )

    contingency = pd.crosstab(tab["missing"], tab["target_bin"])

    # On teste seulement si les deux classes existent
    if contingency.shape[0] == 2 and contingency.shape[1] == 2:
        chi2, p, _, _ = chi2_contingency(contingency)
        results.append({
            "variable": var,
            "p_value": p
        })

chi2_results = pd.DataFrame(results)
chi2_results


La comparaison des proportions de valeurs manquantes entre les classes, testée par un χ² d’indépendance, met en évidence une dépendance significative à la classe pour la variable GERD,


La [Littérature](https://charonne-asso.fr/rgo-asthme/) clinique souligne que :

- le RGO est fréquent chez les patients asthmatiques ;
- ses symptômes (toux, gêne thoracique, dyspnée nocturne) sont peu spécifiques ;
- ils peuvent être attribués à l’asthme lui-même, retardant ou empêchant le diagnostic ;
- le RGO est souvent investigué secondairement, notamment chez les patients avec asthme mal contrôlé ou exacerbations répétées.

> Cela confirme que le fait que la variable gerd soit manquante dépend du statut clinique (classe).

La proportion de valeurs manquantes pour GERD est plus élevée dans la classe avec exacerbations, ce qui suggère une documentation moins systématique/plus difficile chez les patients présentant des épisodes récidivants, compatible avec un mécanisme MAR.

Classe sans exacerbations (0)
- → moins de valeurs manquantes GERD
- → RGO plus souvent recherché 

Classe avec exacerbations (1)
- → plus de valeurs manquantes GERD
- → RGO moins investigué , difficile a diagnostiqué


En l’absence d’association détectable entre la présence de valeurs manquantes et la variable cible pour la majorité des variables, le mécanisme de données manquantes apparaît compatible avec MCAR conditionnel à la classe.
